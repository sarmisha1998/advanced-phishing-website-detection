# Advanced Phishing Website Detection using Machine Learning

## Project Overview

This project presents a Machine Learning-based phishing website detection system that identifies whether a website is legitimate or phishing based on URL and webpage features. The application uses a Random Forest classifier and Explainable Artificial Intelligence (SHAP) to provide accurate and interpretable predictions.

## Features

* Live URL phishing detection
* Batch CSV prediction
* Automatic extraction of 40 engineered features
* Random Forest classification
* Explainable AI using SHAP
* Interactive Streamlit web application
* Model performance dashboard

## Technologies Used

* Python
* Streamlit
* Pandas
* NumPy
* Scikit-learn
* SHAP
* Joblib

## Dataset

PhiUSIIL Phishing URL Dataset
